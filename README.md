# Стена с позами

Игра от первого лица для ребёнка 7 лет. Игра показывает позу, затем на игрока
едет стена с вырезом этой позы; ребёнок повторяет позу, камера судит
повторение. Игра на очки, забег ограничен по времени.

**Играть:** https://vcmacte.github.io/pose-game/

Телефон ставится на штатив, задней камерой на игрока с ~2 м; картинка уходит
на телевизор зеркалированием (Miracast). Нужен Chrome для Android и разрешение
на камеру. Игра устанавливается как приложение и работает офлайн.

## Состояние

Весь код написан и покрыт тестами (559 проверок, из них сквозной прогон забега
на синтетическом игроке со сверкой через replay). **На живом телефоне игра ещё
не запускалась ни разу** — пороги в `src/core/config.ts` выведены из геометрии,
а не измерены. Это последняя задача плана.

## Разработка

```
npm install --maxsockets 4 --no-audit --no-fund
npm run dev
npm run typecheck                 # tsc --noEmit отдельно, без тестов
npm test -- --maxWorkers=8        # tsc --noEmit, затем vitest run
npm run build                     # двухпроходная сборка, см. docs/offline-and-build.md
node tools/log-report.mjs <файл>  # числа забега из журнала с телефона
node tools/replay.mjs <файл>      # записанный скелет через нынешнее ядро
```
