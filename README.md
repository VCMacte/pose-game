# Стена с позами

Игра от первого лица для ребёнка 7 лет. Игра показывает позу, затем на игрока
едет стена с вырезом этой позы; ребёнок повторяет позу, камера судит
повторение. Игра на очки, забег ограничен по времени.

**Играть:** https://vcmacte.github.io/pose-game/

Телефон ставится на штатив, **фронтальной** камерой на игрока с ~2 м; картинка
уходит на телевизор зеркалированием (Miracast). Нужен Chrome для Android и
разрешение на камеру (плюс на микрофон — только для замера задержки тракта,
который взрослый делает раз в жизни устройства). Игра устанавливается как
приложение и работает офлайн.

## Состояние

Весь код написан и покрыт тестами, включая сквозной прогон забега на
синтетическом игроке со сверкой через replay.

**Первый живой прогон на телефоне — 21.10.2026.** Камера и MediaPipe показали
себя хорошо, но забег на 60 секунд завершался за 142 мс: отметка кадра шла с
часов видеодорожки, а не главного потока. Дефект найден и починен.

Осталась последняя задача плана, и она требует телефона, телевизора и ребёнка:
замерить задержку тракта, прогнать 3–4 забега с живой записью скелета и
подкрутить пороги в `src/core/config.ts`. Числа там **выведены из геометрии, а
не измерены** — так и сказано в их doc-комментариях.

## Разработка

```
npm install --maxsockets 4 --no-audit --no-fund
npm run dev
npm run typecheck                 # tsc --noEmit отдельно, без тестов
npm test -- --maxWorkers=8        # tsc --noEmit, затем vitest run
npm run build                     # двухпроходная сборка, см. docs/offline-and-build.md
node tools/log-report.mjs <файл>  # числа забега из журнала с телефона
node tools/replay.mjs <файл>      # записанный скелет через нынешнее ядро
npm run deploy                    # собрать и выложить на GitHub Pages
```

Pages отдаёт ветку `gh-pages` как есть, а не собирает сам: сборка в Actions
требует у токена права `workflow`. `npm run deploy` собирает и перезаписывает
эту ветку слепком. **Пуш в `master` делает это сам** — тем же скриптом, после
тестов (`.github/workflows/deploy.yml`); руками деплой нужен только чтобы
повторить публикацию. Разбор — [`docs/offline-and-build.md`](docs/offline-and-build.md).
