# Меню, настройки и ступени

Читать перед правкой меню, любой настройки, ступеней сложности, тумблеров
словаря поз и доступа взрослого к служебным экранам.

Родитель: [`../CLAUDE.md`](../CLAUDE.md).
Код (запланирован, ещё не написан): `src/adapters/settings.ts`,
`src/shell/screens/*`, `src/core/picker.ts`.
Замысел: [`concept-and-plan.md`](concept-and-plan.md).

## Три экрана и кто их видит

Первый видит ребёнок. Второй и третий — взрослый, вход **долгим удержанием
правого верхнего угла**: приём из `run-game`, чтобы ребёнок не попал туда
случайно. Служебные экраны открываются и посреди забега.

## 1 · Главное меню (ребёнок)

`ИГРАТЬ`; лучший результат за всё время и за прошлый забег; длина забега
`60 / 90 / 120`; сложность `1 / 2 / 3`.

Только эти четыре вещи крупными кнопками. Всё остальное спрятано под взрослого:
цель «ребёнок играет сам» ломается первым же выбором, которого он не понимает.

**Кнопки «Тренировка» нет** — это не-цель первой версии, см.
[`concept-and-plan.md`](concept-and-plan.md). Силуэт включается тумблером в
настройках забега.

## 2 · Настройки забега (взрослый)

| Группа | Настройки |
|---|---|
| Такт | превью `1.5 / 2.0 / 2.5 / 3.0`, ход стены `1.5 / 2.0 / 2.5 / 3.0`, пауза после приговора `0.5 / 0.8 / 1.2` |
| Помощь | силуэт поверх выреза (вкл/выкл), превью камеры в забеге (`вкл / поле / выкл`) |
| Судейство | строгость (`мягко / норма / строго`), сдвиг на задержку `0 / 150 / 250 / 400` мс |
| Словарь | присед, наклоны, асимметричные руки, профильные позы — по отдельности |
| Звук | громкость |

Порог голосования и длина окна судейства в настройки **не вынесены** — только в
отладку: это не вкусовые параметры, а следствия измеренной частоты кадров.
→ [`judging.md`](judging.md)

**Настройки читаются живо.** Смена строгости или силуэта действует со
следующего раунда, без перезапуска забега: иначе взрослый, подкручивающий
строгость рядом с играющим ребёнком, вынужден обрывать забег.

## 3 · Служебный экран (взрослый)

| Группа | Содержимое |
|---|---|
| Журнал | сессий / событий, размер (`X МБ из 25`), период; `СОХРАНИТЬ И ПОДЕЛИТЬСЯ`, `Убрать выгруженное`, `Очистить журнал` |
| Задержка тракта | измеренное значение и разброс последнего замера; `ИЗМЕРИТЬ ЗАДЕРЖКУ` |
| Версия | номер сборки и дата, состояние модели позы в кэше; `Проверить обновление`, `Сбросить офлайн-кэш` |
| Отладка | источник позы (`камера / фейк`), конвейер (`авто / stream / bitmap / main`), сплошная запись скелета, скелет+эталон поверх видео, метрики в забеге, пересдать калибровку |

→ [`log-and-storage.md`](log-and-storage.md),
[`audio-and-latency.md`](audio-and-latency.md),
[`offline-and-build.md`](offline-and-build.md)

## Три ступени сложности

| Ступень | Что в игре | Такт (превью / стена) |
|---|---|---|
| 1 | фронтальные симметричные, стоя на двух ногах | 3.0 / 3.0 |
| 2 | + асимметричные руки, + наклон корпуса | 2.5 / 2.5 |
| 3 | + присед, + опора на одной ноге, + профильные | 2.0 / 2.0 |

Ступень N включает всё с ней и ниже. Выбирается кнопкой.

**Ступеней три, а не пять.** Пять на 13 поз давали по 1–3 позы на ступень, и
правило «не повторять предыдущую позу» становилось невыполнимым.

**Тихой автоадаптации нет.** В `run-game` её убрали сознательно: ребёнок не
понимает, почему вдруг стало легче, а взрослый не может повторить условия
замера.

## Конфликт тумблеров словаря со ступенями

Тумблеры **вычитают** из пула поз. Ступень 3 с выключенным приседом, наклонами
и профилем оставляет пул почти пустым.

**Если в пуле остаётся меньше трёх поз, тумблер блокируется в интерфейсе** с
пояснением. Так выбор следующей позы остаётся чистой функцией и не обзаводится
состоянием «пул опустел» — а именно в таком состоянии игра либо падает, либо
выдаёт одну позу подряд.
→ [`judging.md`](judging.md)
